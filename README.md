# Mouse Automation 45

Mouse Automation 45 is a powerful Python-based auto-clicker that allows users to easily automate mouse clicks in various applications. Designed for both casual users and developers, this tool enhances efficiency by reducing repetitive tasks with customizable click patterns and intervals.

## Features
- **Custom Click Timing**: Set precise intervals between clicks to simulate human-like interaction.
- **Click Pattern Flexibility**: Choose between single clicks, double clicks, or even custom sequences for versatile automation.
- **Hotkey Activation**: Start and stop the auto-clicker instantly using predefined keyboard shortcuts for convenience.
- **Cross-Platform Compatibility**: Works seamlessly on Windows, macOS, and Linux, making it accessible for all users.

## Installation

To get started with Mouse Automation 45, simply clone the repository and install the necessary dependencies:

```bash
git clone https://github.com/Developer/mouse-automation-45.git
cd mouse-automation-45
pip install -r requirements.txt
```

## Basic Usage

Once installed, you can run the auto-clicker using the following command:

```bash
python auto_clicker.py
```

By default, the auto-clicker will initiate with a standard click interval of 1 second. Customize the timing and click pattern in the `config.py` file. Use the hotkey `Ctrl + Shift + A` to start or stop the clicking process.

For more advanced usage, refer to the examples provided in the `examples` folder.
